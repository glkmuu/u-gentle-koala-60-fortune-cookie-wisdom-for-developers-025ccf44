One original fortune-cookie line of wisdom for a software developer, 120 characters or fewer.

> Beware the bug you cannot reproduce — it has already learned your name.

`main.py` writes that single line to `entry.txt` (71 characters, UTF-8, deterministic — same run, same bytes, no trailing newline). No network, no randomness, no dependencies, Python 3.13 standard library only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
